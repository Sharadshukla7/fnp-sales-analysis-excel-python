#  FNP Sales Analysis Dashboard

##  Project Overview

The **FNP Sales Analysis Dashboard** provides an in-depth analysis of sales performance, customer behavior, and product insights for *Ferns N Petals (FNP)*.  
Built using **Excel, Python**, this dashboard showcases key business metrics and visualizes trends to support **data-driven decision-making**.

---

## 🎯 Objectives
- Analyze sales data to uncover revenue trends and customer insights.  
- Identify top-performing products, categories, and regions.  
- Understand the impact of delivery time and seasonal occasions on sales.  
- Combine **Python automation**, **Excel KPIs & visualization** for end-to-end analysis.  

---

##  Tools & Technologies Used

| Tool / Technology | Purpose |
|--------------------|----------|
| **Python (Pandas, NumPy)** | Data cleaning, transformation, and analysis |
| **Microsoft Excel** | Exploratory data analysis and KPI calculations and dashboard creation |

##  Key Performance Indicators (KPIs)

| KPI | Description | Value |
|-----|--------------|-------|
| **Total Revenue** | Overall sales generated | ₹3,520,984 |
| **Total Orders** | Number of completed transactions | 1,000 |
| **Average Delivery Time** | Average time (in days) taken to deliver an order | 5.53 Days |
| **Average Customer Spending** | Average amount spent per order | ₹3,520.98 |

## 📊 Dashboard Insights

### 🔸 Revenue by Category  
Displays revenue distribution across product categories such as **Colors, Soft Toys, and Sweets**, helping identify high-performing segments.

### 🔸 Revenue by Hour (Order Time)  
Highlights hourly order trends to identify **peak buying times**, useful for targeted marketing.

### 🔸 Top 5 Products by Revenue  
Shows top-performing products such as **Magman Set** and **Quia Gift**.

### 🔸 Top 10 Cities by Orders  
Lists the cities with the highest number of orders — key for **regional performance tracking**.

### 🔸 Revenue by Months  
Visualizes monthly revenue patterns to analyze **seasonal demand** and festival-based trends.

### 🔸 Revenue by Occasions  
Breaks down revenue by special events like **Anniversary, Valentine’s Day, Raksha Bandhan, and Diwali** to understand **occasion-driven sales spikes**.

---

## 🔍 Data Preparation Workflow

### 1. **Data Cleaning (Python)**
- Converted date columns to datetime format.  
- Derived new columns such as *Month*, *Delivery Time*, and *Total Sales*.
- Calculated core KPIs for visualization in excel.
 

### 2. **Exploratory Data Analysis (Excel)**
- Used pivot tables and descriptive statistics to explore trends.
- Applied filters for **Order Date** and **Occasion** to enhance exploration.
- cleaned dataset and created interactive visuals.  

---

## 📈 Business Insights
- **Colors** category generates the highest revenue.  
- **February and August** show sales peaks due to seasonal and festive occasions.  
- **Evening hours (6–9 PM)** record maximum customer activity.  
- **Valentine’s Day and Anniversary** events significantly boost revenue.
